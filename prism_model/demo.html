A little more than a green light.

Run a request to see the decision and the evidence behind it.

What “Ready” means. The request can go to a buyer for review. This model checks identifying information; it does not choose an exact SKU, establish engineering suitability, or approve a purchase.

A learning project, in the open. These are fictional procurement policies and AI-authored examples. The model can make mistakes. Inference runs locally and the app does not save your requests.

02 /Under the hood

Learn the language.
Check the facts.

We start with an openly licensed Ettin encoder and train our own task-specific heads. The neural model identifies the item and its evidence. Code compares the extracted facts against a small, explicit purchasing policy.

Find the evidence
