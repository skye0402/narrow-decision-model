First learning/demo snapshot: CPU inference with source-linked neural evidence and explicit policy checks across six purchasing categories.

The model asset is the exact frozen demo bundle, including encoder, task heads, tokenizer and calibration. Its SHA-256 checksum is in artifacts.json. Install it using scripts/install_artifact.py, then run scripts/serve_demo.py.

Artificial policies and AI-authored, unreviewed labels. Demo-only candidate; no production qualification or blind acceptance result. Training archives and ancestor checkpoints are not included in this initial release; see REPRODUCING.md.
